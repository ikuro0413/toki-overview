サイト制作のしくみ図解
HOW THIS SITE IS BUILT — DetoxNewsを例に

AIと無料ツールでWebメディアを作って運用する全体像

プログラミング未経験の人向け。実際に運用中のメディア「DetoxNews」（記事63本・公開11日）で使っている構成をそのまま図解する。

1. 全体像 — たった1つのループを回しているだけ

難しそうに見えるが、やっていることは5工程のループが1つあるだけだ。記事を書いて、公開して、数字を見て、次の記事を決める。この繰り返しでサイトが育つ。

人間の仕事は「方針を決めること」と「OKを出すこと」だけ。執筆・修正・公開・分析の作業自体はAI（Claude Code）が実行する。

2. 登場するツール — 役割は3種類しかない

使うツールは多く見えるが、役割で分ければ「作る」「届ける」「測る」の3種類しかない。

作る
Claude CodeAI

制作の実行役。「◯◯の記事を書いて」と指示すると、執筆からHTML化、公開作業まで全部やる。

作る
GeminiAI・無料〜

記事のトップ画像を生成する。「白背景・線画・オレンジ」と指定して全記事のテイストを統一。

作る
HTML / CSS技術

サイトの中身そのもの。WordPressのような管理ツールは使わない「静的サイト」なので、壊れにくく表示が速い。

届ける
GitHub無料

ファイルの保管庫。変更履歴が全部残る「タイムマシン付きの金庫」。ここに置いたものが正本になる。

届ける
GitHub Actions無料

保管庫に変更が届いたら、自動でサーバーへファイルを転送する仕組み。手作業のアップロードはゼロになる。

届ける
エックスサーバー月1,000円前後

サイトを24時間公開し続ける本番サーバー。この構成で唯一の固定費。独自ドメインの管理もここ。

測る
Google Search Console無料

「どんな検索語で何回表示・クリックされたか」が分かる。次に書く記事はこのデータから決める。

測る
Google Analytics（GA4）無料

来た人がどのページを何秒読んだか、どこから来たかが分かる。記事の質の通信簿。

測る
Bing Webmaster Tools無料

Bing検索への登録。ChatGPTの検索がBingを参照するため、AI時代の保険として入れておく。

測る
楽天アフィリエイト無料

商品紹介記事の収益化。リンク経由で商品が買われると報酬が入る。クリック数もここで測る。

3. 公開のしくみ — ファイルはどう流れるか

いちばん「魔法」に見える部分がここ。実際はファイルのバケツリレーで、逆流はない。

ポイントは真ん中にGitHubを挟むこと。サーバーに直接ファイルを置く方式と違い、「いつ・何を・なぜ変えたか」が全部記録に残るので、失敗してもいつでも巻き戻せる。

4. 記事1本ができるまで — 実際の手順

ネタを決める（人間＋AI）

Search Consoleを開き「表示されているのにクリックされていない検索語」「順位が付き始めた検索語」を探す。勘ではなくデータでネタを選ぶ。

記事を書く（AI）

Claude Codeに「この検索語向けの記事を書いて」と指示。サイト共通の型（冒頭に結論→本文→FAQ→関連記事リンク）に沿ったHTMLが出来上がる。

画像を作る（AI）

Geminiでトップ画像を生成。テイスト指定を毎回同じにして、サイト全体の見た目を揃える。

組み立てる（自動）

ビルドスクリプトを1回実行すると、トップページの新着一覧・カテゴリページ・月別アーカイブ・検索エンジン向けの地図（sitemap）が全部自動で更新される。手で直すのは記事本体だけ。

公開する（自動）

GitHubにpushすると約30秒で本番サイトに反映。アップロード作業は存在しない。

数字を見て次を決める（人間＋AI）

数日後にSearch ConsoleとGA4を確認。当たった記事の周辺を深掘りし、外れた記事はタイトルを直す。ここが工程1に戻る。

5. 費用 — 固定費はサーバー代だけ

項目費用備考
エックスサーバー月1,000円前後唯一の固定費。ドメイン代込みの目安
GitHub / Actions無料この規模なら無料枠で十分
Google系の計測ツール無料Search Console・GA4・Bingすべて
Claude Code / Gemini各サービスの利用料AI利用分。人を雇うより桁違いに安い

WordPressの有料テーマも、デザイナーへの外注費も、更新代行費もかからない。「静的サイト＋AI＋無料インフラ」がこの構成の核だ。

6. 用語ミニ辞典

用語意味
静的サイトあらかじめ作ったHTMLファイルをそのまま配るだけのサイト。仕組みが単純なので速くて壊れにくい
リポジトリGitHub上の保管庫1つぶんの単位。サイト1つ＝リポジトリ1つ
push（プッシュ）パソコンで変えたファイルをGitHubの保管庫に送ること
デプロイファイルを本番サーバーに反映して公開すること。この構成ではpushすると自動で起きる
ビルド記事を追加したとき、目次や一覧ページを組み立て直すこと。スクリプトが自動でやる
インデックスGoogleがページを検索結果に載せられるよう登録すること。公開から数日かかる
SEO検索結果で見つけてもらいやすくする工夫の総称
sitemap / llms.txt検索エンジン向け・生成AI向けの「サイトの地図」ファイル。ビルドで自動生成される
