6. 方針 — 検証中の仮説と、次の7日

今日立てた仮説: 「セクション追記では順位が動かない。独立記事化が要る」
8/16に総合比較記事へ「ニトリとワークマン、どちらを買うべきか」のセクションを追記したが、4変種57表示・0クリック・順位10.5から動いていない。一方、同じリカバリーウェア圏で独立記事にしてある「バクネとワークマンの違い」は7.1位まで来ている。セクション（10.5位）と独立記事（7.1位）という3.4ポイントの差が、そのまま独立記事化の効果仮説になる。今日はこれを3本で検証する。

優先度A: インデックス登録をリクエストする

  • 今回いちばんの問題は記事の質ではなくインデックスされていないことだった（3-3）。sakana-ga-sodatsu と revenge-yofukashi-yakin は3〜4日たっても表示ゼロ、8/19公開の3本も未判定
  • Search Consoleの URL 検査からインデックス登録を明示的にリクエストする。過去に bakune-workman-hikaku などで実施した手順と同じ
  • これをやらないと、独立記事化の仮説も「指名×疑問の単体ページ」の仮説も検証が始まらない

優先度A': AIトラブル解決クラスタを厚くする

  • 今回クリックを4倍にした ai-assistant-off の周辺に、「消し方・非表示・無効化」という新しいクエリ群が立ち上がっている（ai消し方9／aiアシスタント 非表示6／デジタルアシスタント アプリ 無効 化5／最新 ai アシスタント 削除 方法4）
